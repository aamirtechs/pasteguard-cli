pasteguard-cli

Scan text for personal data and secrets before you share a file or commit it.

Your report will appear here.

Detectors: EMAIL, PHONE, SSN, CREDIT_CARD (Luhn checked), AWS_ACCESS_KEY, GITHUB_TOKEN, SLACK_TOKEN, PRIVATE_KEY, JWT. Reported values are redacted to their last 4 characters, exactly like the CLI. The sample uses fake values only, assembled in your browser from parts so no scanner-shaped string sits in this page.
